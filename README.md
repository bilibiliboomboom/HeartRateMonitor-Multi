# HeartRateMonitor Multi

Android 多设备 BLE 心率监测器，面向泳队/团体训练场景。

## v1.1.0
- 同时连接多台广播标准 BLE Heart Rate Service (0x180D) 的手环/手表
- 每台设备可设置运动员姓名，名称会保存在本机
- 每台设备独立显示实时 BPM、信号 RSSI、数据更新时间和最近心率趋势
- 训练记录开始/停止，按设备记录时间戳与 BPM
- 导出 CSV，可用于 Excel 做训练复盘
- 横屏/竖屏切换、单台移除、单台断开、全部断开
- Android 8.0+

## 使用
1. 在每只手环/手表上开启心率广播。
2. 接收手机开启蓝牙并授予附近设备权限。
3. 点击扫描，逐一连接设备。
4. 点击卡片上的设备名称可改成运动员姓名/泳道编号。
5. 训练前点击「开始记录」，结束后点击「停止记录」，再导出 CSV。

设备必须提供标准 BLE 心率服务。小米手环 10、COROS 等设备若开启了兼容的心率广播即可连接。水下 2.4GHz BLE 信号衰减明显，接收手机应放池边，不能保证人在水下持续收数。
